## 에셋 권한·공개 소스에서 남은 점

1. `assets/references/itch/muscle-runner-reference.png`는 Git 추적 대상이다.
   [제작자 이용 조건](https://pixelspriteshop.itch.io/42pixelcharacter)을 이번에 다시 확인했으며,
   원본 에셋/팩을 개별 다운로드 대상으로 재업로드·재배포하는 제한이 있다.
   현재 ZIP에는 들어가지 않지만, 공개 GitHub 소스에 참고용 원본을 그대로 올리는 것은
   별도 점검이 필요하다. 공개용 소스에서는 원본 대신 출처 링크를 보관하거나 허락을 확보한다.
   원본을 제외할 경우 manifest 항목도 함께 조정해야 현재 전체 목록 검사가 통과한다.
   이미 공개된 이력이 있는지는 이번 로컬 점검에서 확인하지 않았다.
2. 기존 유니콘 원본의 개별 제작자·제작 도구 기록이 누락되어 있다.
   새 편집본과 내보내기 과정은 기록했지만 이전 원본의 권한까지 새로 입증한 것은 아니다.
   manifest의 `project-original`은 프로젝트 기록에 따른 분류다.
3. Hyper Light Drifter는 색·명암·픽셀 형태의 참고 대상으로 사용했다.
   해당 게임의 추출 에셋, 캐릭터, 로고는 제출물에 포함하지 않았다.
   현재 규정 페이지에서 생성형 AI에 관한 별도 금지 조항은 확인되지 않았지만,
   이것만으로 권한 조건 충족이나 주최 측 승인을 보증하지는 않는다.

## 브라우저·주제 확인 범위

- Codex 내장 브라우저: 최종 제출 HTML의 실제 새 에셋 화면 확인, 수집된 경고·오류 0건.
- 설치된 Chrome: `file:`로 HTML 직접 열기, 시작 카운트다운·점프·렌더링 확인.
  콘솔에는 로컬 파일의 고유 출처 정책에 관한 오류 1건이 관찰됐다.
  게임 소스에서 자체 파일/프레임 로드를 찾지 못했으나, 확장 기능·도구의 영향인지
  아직 구분하지 못했다. 따라서 Chrome의 무오류 판정은 보류한다.
  내장 브라우저의 추가 `file:` 접근은 브라우저 URL 정책으로 차단되어 재현하지 못했다.
- Firefox: 현재 설치/사용 가능한 환경에서 찾지 못해 미검증. Chrome 최신 버전 여부도 미확인.
- 유니콘과 여러 색의 갈기·꼬리, 다색 포털은 유지했다. 새 팔레트에서는 무지개가
  전보다 덜 직접적으로 읽힐 수 있어, 주제 점수 측면에서는 무지개 연출을 더 명확히 하는 개선 여지가 있다.
