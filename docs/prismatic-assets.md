# Prismatic ruins — 실제 에셋 변경 기록

> 2026-09-08: 현재 편집 원본은 Piskel이며 배경을 추가로 간소화했습니다. 아래는 9월 7일 변경 기록입니다. [현재 작업실 안내](map-asset-workspace.md).

2026-09-07, Hyper Light Drifter를 최대한 참고해 실제 게임 에셋을 수정해 달라는
요청에 따라 러너 PNG와 Canvas 환경 에셋을 변경했다.

## 참고 방향

[Heart Machine 공식 페이지](https://www.heartmachine.com/hyper-light-drifter)의
[청록색 유적 화면](https://images.squarespace-cdn.com/content/v1/619478d0d2aca04773e62fb7/4d2c7f71-e53b-40b9-8217-049ee2f40552/STORE_ScreenShot_02.png)과
[차가운 그림자·발광 효과 화면](https://images.squarespace-cdn.com/content/v1/619478d0d2aca04773e62fb7/d65a2387-e0b6-47b7-8268-afe11f483f98/STORE_ScreenShot_08.png)을
직접 확인했다. 청록·남보라 계열의 그림자, 밝은 산호색 포인트, 단순하고 각진 명암
덩어리, 유적과 발광 기술의 대비를 현재 게임에 적용했다. 기존 유니콘 캐릭터와
2.5D 추격 시점은 유지했다. 해당 게임의 이미지 파일은 프로젝트에 복사하지 않았다.

## 실제로 변경한 것

- **러너 PNG:** 흰색 근육과 무지개색의 복잡한 음영을 아이보리·라벤더 몸체,
  인디고 장비, 산호색·청록색 갈기/꼬리와 굵은 픽셀 덩어리로 변경했다.
- **배경 투명도:** 내보낸 PNG는 배경 알파 0, 캐릭터 알파 255를 사용한다.
  기존 아틀라스처럼 전체 픽셀이 반투명한 상태가 아니다.
- **도로:** 남보라 석재 색, 엇갈린 타일 이음새와 작은 마모 흔적을 추가했다.
  두꺼운 노란 도로 가장자리를 가는 청록색 발광 경계로 바꿨다.
- **환경:** 시작 구간의 화덕 형태를 조각난 유적 기둥과 빛나는 코어로 바꾸고,
  원경에 층을 이루는 폐허 실루엣과 창문 빛을 추가했다. 나머지 구간의 기계·교량·
  잔해도 공통 팔레트를 적용했다.
- **위험·효과:** 용암과 불은 자홍·산호색으로, 안전한 기술 발광은 민트 계열로
  구분했다. 경고 띠의 밝은 색과 장애물 실루엣은 유지했다.
- **팔레트 관리:** `src/palette.mjs`에서 환경, 캐릭터 대체 렌더러, 런타임 PNG
  내보내기와 카탈로그 배경 색상을 함께 관리한다.

이전 PNG는 `assets/concepts/unicorn-chibi-atlas-legacy.png`에 보존했다.
카탈로그에서 `runner` 또는 `unicorn`을 검색하면 이전 버전과 새 원본·결과물을
비교할 수 있다. 콘셉트/외부 참고 자료는 실행용 에셋과 구분해 유지했다.

## 원본과 재현 가능한 내보내기

아트 수정에는 기본 제공 **ImageGen** 도구를 사용했다. 생성된 원본은
`assets/concepts/unicorn-prismatic-source.png`이며, 정확한 두 프롬프트는
[프롬프트 기록](prismatic-image-prompts.md)에 저장했다.

도구는 투명 배경 요청에도 실제로 RGB 체크무늬 배경을 출력했다. 선택한 생성본을
그대로 보관하고, 게임용 변환 단계에서 아래 조건으로 배경과 팔레트를 처리했다.
이는 선택한 원본을 위한 내보내기 설정이며 범용 배경 제거 모델은 아니다.

| 항목 | 현재 설정 |
| --- | --- |
| 입력 원본 | 2120 × 742 RGB PNG |
| 크롭 | x=0, y=24, width=2120, height=706 |
| 출력 | 160 × 56, 32 × 56 프레임 5개 |
| 샘플링 | 각 출력 픽셀 중심에 대응하는 최근접 원본 픽셀 |
| 매트 제거 | R·G·B가 모두 240 이상이면 투명 |
| 알파 처리 | 원본 알파가 128 미만이면 투명, 나머지 본체는 불투명 |
| 색상 | 공유 러너 팔레트 11색 + 라벤더 `#c1b3cf` + 자홍 그림자 `#ac3a68` |
| 양자화 | RGB 제곱거리 기준 최근접 팔레트 색, 디더링 없음 |
| PNG | 8-bit indexed, 13색 + 투명 인덱스, DEFLATE level 9 |
| 재현 명령 | `npm run assets:generate` |

입력 그림, 크롭과 색상 설정이 같으면 PNG 바이트와 임베딩 코드도 같다.
생성 모델 자체의 출력을 재현한다는 뜻은 아니다. 테스트와 빌드는 원본·레시피에서
계산한 PNG가 저장된 실행용 PNG와 같은지, 임베딩 코드가 PNG와 같은지 확인한다.

현재 원본의 밝은 몸체는 매트보다 어두운 라벤더·아이보리로 구분된다. 원본이나
색을 새로 바꿀 때는 하얀 본체가 매트 임계값에 들어가지 않는지, 발/뿔/꼬리가
프레임 경계에서 잘리지 않는지 카탈로그의 밝은 배경과 어두운 배경 모두에서 확인한다.

## 검증 결과

| 지표 | 이전 | 변경 후 |
| --- | ---: | ---: |
| 러너 PNG | 2,402 B | 1,737 B |
| 팔레트 색 수 | 24 | 14 (투명 포함) |
| 완전 투명 픽셀 | 0 | 5,504 |
| 반투명 픽셀 | 8,960 | 0 |
| 불투명 픽셀 | 0 | 3,456 |
| 제출 ZIP | 12,767 B | 12,341 B |
| ZIP 남은 용량 | 545 B | 971 B |

90개 테스트가 통과했다. 원본에서 PNG를 다시 내보내는 검사, 투명도/팔레트/크롭
검사, 실제 스프라이트 프레임 선택, 대체 렌더링, 모든 장애물, 35.058초 자동 완주,
단일 HTML ZIP 및 13,312 B 제한을 확인했다. 실제 제출 HTML의 시작 화면도
브라우저에서 확인했다. 타일 이음선을 월드 좌표에 고정해 카메라 이동에 맞춰
흐르도록 수정했고, 회귀 테스트로 확인했다. Chrome에서 로컬 HTML의 시작과
점프도 확인했다. 전체 대회 적합성은 [JS13K 점검 기록](js13k-asset-compliance-2026-09-07.md)을 참고한다.

다섯 프레임의 순서, 플레이어 크기·기준점, 카메라, 입력과 충돌 판정은 유지했다.
일반·이단 점프 및 착지·충돌은 여전히 각각 공통 프레임을 사용한다. 새 포즈를
추가하는 작업은 이번 색·형태 수정과 별개다.
