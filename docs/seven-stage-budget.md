# 7스테이지 최소 빌드 · 2026-09-08

> 이 문서는 초기 용량 검증 기록이다. 현재 코스와 최신 용량은 [코스 설계 보고서](stage-design.md)를 참고한다.

7개 시험 코스, 순차 진행, 실패 시 현재 스테이지 재시도, 최종 완료 후 재시작을 포함해 ZIP 제한을 통과했다.

| 항목 | 바이트 |
| --- | ---: |
| 이전 1스테이지 빌드 | 12,297 |
| 현재 7스테이지 빌드 | 12,624 |
| 증가량 | 327 |
| JS13K 제한 | 13,312 |
| 남은 공간 | 688 |

## 공유하는 것

- 캐릭터 아틀라스, 장애물·구름·도로 렌더러와 충돌/점프 물리
- 하나의 1000 m 코스 템플릿: 지형 배열을 공유하고 장애물 배열은 실행 시 생성
- 스프링과 틈의 관계, 45초 제한

각 코스는 무지개 대표색, 홀수/짝수 슬롯의 좌우 배치, 0.1초 단위 위험물 위상 차이로 구분한다. 장애물 배열은 스테이지 사이에 수정 사항이 전파되지 않도록 별도 생성한다. 원본 설정 파일의 7개 팔레트는 모두 빌드에 포함된다.

## 현재 완성도

**7개의 완성된 고유 맵은 아니다.** 전체 진행 구조와 용량을 검증하기 위한 패턴 변형 시험 코스다. 추가 에셋 없이 스테이지마다 전혀 다른 지형을 만드는 작업과 난이도/재미 조정은 다음 콘텐츠 단계다.

688바이트를 전부 콘텐츠에 사용하지 않고 약 500바이트를 수정 여유로 남기면, 현재 구조에서 순증할 수 있는 공간은 약 188바이트다. 더 큰 콘텐츠 추가에는 기존 데이터/표현의 교체 또는 추가 압축이 필요하다. 색상 등 작은 설정 변경도 최종 ZIP을 다시 측정해야 한다. 빌드의 13,312바이트 차단 조건은 유지했다.

## 검증

- 전체 테스트 117개 통과.
- 7개 코스 모두 실제 시뮬레이션 코드로 무피격 완주: 각각 35.058초 / 45초.
- 실제 게임 루프에 키보드 입력을 보내 1→7 진행과 최종 완료 후 1로 복귀 확인. 이 전환 테스트만 코스 길이를 줄이고, 완주 테스트는 원래 길이를 사용한다.
- 순수 전환 테스트로 실패/타이틀 상태에서 현재 스테이지 유지 확인.
- 설정 저장 시 7번 스테이지까지 생성 코드 반영, 오래된 저장 요청 거부 확인.
- 관리 페이지에서 7번 실제 시험 코스와 ZIP 빌드 버튼 확인; 브라우저 콘솔 오류·경고 없음.
- 제출 ZIP에는 index.html 하나만 포함. 원본 Piskel·관리 페이지·보고서는 제외.

용량 통과는 대회 전체 요건의 최종 인증이 아니다. 이전 에셋 출처 검토 사항 2건은 그대로 남아 있다.
